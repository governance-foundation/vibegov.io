# Authored-page heroes

## Intent and scope
Publish the approved generated artwork for live review on VibeGov, as requested by the site owner. Governing issue: [#226](https://github.com/governance-foundation/vibegov.io/issues/226).

Development mode. Add page-specific heroes to 32 blog articles, Agent Roles, and 71 documentation, FAQ and published-rule pages. Preserve the two existing blog heroes, homepage SVG, all article/rule prose, and canonical governance sources. This slice does not change machine-readable role packs or autogenerated listing pages.

## Requirements
- PAGE-HERO-001: Each of the 104 supplied mappings has the correct visible hero with descriptive alternative text.
- PAGE-HERO-002: Images retain their artwork and aspect ratio, reserve layout space, scale within the content column, and offer smaller responsive sources.
- PAGE-HERO-003: Each mapped page uses its own compatible JPEG social-preview asset through Docusaurus metadata.
- PAGE-HERO-004: Existing heroes, homepage artwork, prose, URLs, headings and canonical rule files remain unchanged.
- PAGE-HERO-005: Build, typecheck, existing smoke tests, emitted hero/metadata verification, independent review, and exact-commit production verification precede completion.

## Design
Keep Docusaurus frontmatter and plain MDX image markup. Publish optimised 640/1280-pixel WebP variants and a 1280-pixel JPEG fallback/social image; originals remain in the supplied asset package. Explicit dimensions and global scoped image styling prevent overflow and layout shift. Use no image cropping. A source-to-route manifest and validation script make coverage repeatable.

## Delivery
Branch from develop, scoped PR into develop, then explicit promotion to main only after review and verification. Do not promote unrelated differences. Current main and develop baseline: 1d02157d1cdb206edca85eb8f4ebb0eb28a7cf88.
