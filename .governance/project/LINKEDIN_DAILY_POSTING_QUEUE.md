# VibeGov LinkedIn Daily Posting Queue

Issue: #136
Status: draft operational companion to the narrative schedule
Purpose: make it easy to pick one VibeGov article each day and post it with ready-to-use text, tags, and direct link.

Companion artifact: `.governance/project/LINKEDIN_ARTICLE_NARRATIVE_SCHEDULE.md`

## How to use this file

1. Start at the top of the queue.
2. Pick the next unpublished item.
3. Publish the **Governance Foundation page** post first.
4. Repost/share that Governance Foundation post from **Max's personal profile** with a short personal take written as repost commentary, not as a duplicate second company-style post.
5. Use the **Direct link** in the Governance Foundation post.
6. Use the suggested tag set that fits the destination.
7. Mark the item as posted by adding a date in the `Posted` column.

## Posting defaults

- Keep the post text short enough for LinkedIn skimming.
- If you want a stronger CTA, append: `Full article here:` before the link.
- Governance Foundation page copy should be clean and institutional.
- Max personal repost copy should be broader and slightly more reach-oriented.
- Max personal repost copy should read like a real personal repost/share caption reacting to the Governance Foundation post, not like the same post body repeated on a personal profile.
- Default tag style for Governance Foundation page posts: **4-6 relevant tags**.
- Default tag style for Max personal reposts: **6-10 tags** when deliberately optimizing for reach.
- Stable core tags for most posts: `#AIGovernance #AIEngineering #SoftwareDelivery #VibeGov`
- Add 1-3 topic-specific tags for the company-page version and 2-6 topic-specific tags for the personal version when useful.
- If a post performs well, follow it with the next item in the same phase to preserve narrative momentum.

## Response-format rule for ad hoc posting help

When generating live posting help in chat, the default answer format should be:

`GF PAGE — copy/paste this exactly`

`MY PAGE — copy/paste this exactly`

with paste-ready text under each heading and no extra explanation unless explicitly requested.

Additional rule: if Max is reposting/sharing the already-live Governance Foundation post from his personal profile, the `MY PAGE` block must be written as personal repost commentary/caption, not as duplicated Governance Foundation post body text.
