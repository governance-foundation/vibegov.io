# Do I need Codex or a specific AI provider?

No.

VibeGov is designed to be provider-neutral. It works best with agents or IDE assistants that can read repo files, follow project rules, and report evidence back into the work surface.

Codex, Claude, Cursor, and other tools may need different instruction entrypoints, but the delivery contract should stay the same: clear issue, clear mode, clear proof, clear handoff.
