# Can I use VibeGov in an existing repo?

<img className="page-hero" src="/img/heroes/docs/can-i-use-vibegov-in-an-existing-repo-hero.jpg" srcSet="/img/heroes/docs/can-i-use-vibegov-in-an-existing-repo-hero-640.webp 640w, /img/heroes/docs/can-i-use-vibegov-in-an-existing-repo-hero-1280.webp 1280w" sizes="(max-width: 640px) 100vw, (max-width: 996px) 90vw, 960px" width="1280" height="720" alt={"a mature flat mosaic of dark glass tiles with one new teal tile being carefully inserted into an existing empty space, preserving the surrounding assembly"} decoding="async" />

Yes.

For an existing repo, use **bootstrap update** instead of treating the project like a blank slate. The update path preserves valid local files, detects existing project conventions, and repairs or adds the missing governance pieces.

If the repo has active work in progress, resolve or document that state first. VibeGov should not hide dirty branches, unresolved decisions, or partial work under a new governance scaffold.
