# Is VibeGov a tool, framework, protocol, ruleset, or SaaS?

<img className="page-hero" src="/img/heroes/docs/is-vibegov-a-tool-or-framework-hero.jpg" srcSet="/img/heroes/docs/is-vibegov-a-tool-or-framework-hero-640.webp 640w, /img/heroes/docs/is-vibegov-a-tool-or-framework-hero-1280.webp 1280w" sizes="(max-width: 640px) 100vw, (max-width: 996px) 90vw, 960px" width="1280" height="720" alt={"a small open metal framework cage surrounding a single coherent glass mechanism, a local governance framework rather than an application screen"} decoding="async" />

VibeGov is a repo-local governance framework for AI-assisted software delivery.

It is not a hosted SaaS product or a single agent runtime. It is a repo-carried set of rules, docs, role files, prompts, and evidence expectations that help humans and AI agents work from the same delivery contract.

Use it when you want clearer intent, cleaner handoffs, and better proof of done without adopting a new project-management platform.
