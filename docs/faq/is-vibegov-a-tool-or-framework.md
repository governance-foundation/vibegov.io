# Is VibeGov a tool, framework, protocol, ruleset, or SaaS?

VibeGov is a practical governance layer for AI-assisted software delivery.

It is not a hosted SaaS product or a single agent runtime. It is a repo-carried set of rules, docs, role files, prompts, and evidence expectations that help humans and AI agents work from the same delivery contract.

Use it when you want clearer intent, cleaner handoffs, and better proof of done without adopting a new project-management platform.
