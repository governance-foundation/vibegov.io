# When do I use bootstrap update?

<img className="page-hero" src="/img/heroes/docs/when-do-i-use-bootstrap-update-hero.jpg" srcSet="/img/heroes/docs/when-do-i-use-bootstrap-update-hero-640.webp 640w, /img/heroes/docs/when-do-i-use-bootstrap-update-hero-1280.webp 1280w" sizes="(max-width: 640px) 100vw, (max-width: 996px) 90vw, 960px" width="1280" height="720" alt={"A replacement glass segment hovers over a gap in an intact metal ring."} decoding="async" />

Use **bootstrap update** when a repo already has partial bootstrap state and needs repair/normalization.

This is the canonical bootstrap contract run in **`update` mode**.
It uses the same completion bar as `init`; it just preserves valid artifacts and repairs missing or weak ones.

- [Bootstrap](/docs/bootstrap)
