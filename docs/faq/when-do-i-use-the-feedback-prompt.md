# When do I use the feedback prompt?

<img className="page-hero" src="/img/heroes/docs/when-do-i-use-the-feedback-prompt-hero.jpg" srcSet="/img/heroes/docs/when-do-i-use-the-feedback-prompt-hero-640.webp 640w, /img/heroes/docs/when-do-i-use-the-feedback-prompt-hero-1280.webp 1280w" sizes="(max-width: 640px) 100vw, (max-width: 996px) 90vw, 960px" width="1280" height="720" alt={"a translucent glass funnel passing a few rough geometric fragments through a fine metal mesh into one polished cyan bead, scrubbed durable feedback"} decoding="async" />

Use the **bootstrap feedback prompt** after bootstrap init/update when you want durable, scrubbed feedback.

Expected output:
1. local historical artifact: `.governance/project/bootstrap/history/<timestamp>/feedback.md`
2. refreshed current reporting file: `.governance/project/bootstrap/FEEDBACK.md`
3. issue-ready title/body for `governance-foundation/vibegov.io`

If asked to file automatically, file and return the created issue URL.
